04 HOW IT WORKS

Three commands.
One public app.

01

Install dependencies

Install Express and everything declared in package.json.

npm install
02

Start the application

Run the Node.js server locally on port 3000.

npm start
03

Expose with ngrok

Create a secure tunnel from a public HTTPS address to localhost.

ngrok http 3000
